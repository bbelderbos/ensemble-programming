How it works

  1. 1

    Create a session

    Set a goal and share the link. Everyone joins from their browser.

  2. 2

    Join the rotation

    Take a turn as driver, navigator or timekeeper, or sit in as an observer to watch and learn.

  3. 3

    Code in segments

    The driver types, the navigator steers. When time is up, roles rotate and the team debriefs before the next segment.

Built for the way ensembles work

⚡ Live shared editor

Every keystroke streams to the whole team instantly.

⌨️ Driver-only typing

Ideas go through someone else's hands, the core rule of ensemble programming.

🐍 Python in your browser

Code runs locally via Pyodide, with highlighted tracebacks. Nothing runs on the server.

⏱️ Rotation timer

5-minute segments, started by the timekeeper, with a break to debrief.

👀 Observers

Managers, new hires or students can watch without taking a turn.

🔓 Open source

FastAPI, WebSockets and htmx. Read the code.
